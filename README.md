# TFG-Backend

Backend project for Digital Twin

## Main Features

- RESTful API for managing farms, equipment, and historical data.
- Real-time communication using WebSockets.
- MQTT integration for receiving and processing sensor data.
- MongoDB as the main database.
- Modular and scalable architecture.

## Project Structure

- `/controllers`: API route controllers.
- `/services`: Business logic, MQTT, and WebSocket integration.
- `/models`: Mongoose data models.
- `/config`: Application configuration.
